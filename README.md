# Pacman
A recreation of the original pacman game in C.


We chose to recreate Pacman for our Systems Programming final project because it is a nostalgic and iconic game. The visuals are simple to create and sprites would only be able to go in 4 directions: Up, Down, Left, Right. With simple visuals, clear limitations in movement, and score and life counters, we hope to recreate the game in C.

We expect the following challenges:
- collision detection with Pacman and ghosts
- randomness of ghost directions
- proximity detection when a ghost recognizes that Pacman is nearby
- creating a maze with restrictive walls
- track defeats for respawn logic
